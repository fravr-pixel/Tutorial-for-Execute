How to use Execute?

Thank you for installing Execute!

Wanna know how to use it? Just go through this tutorial!


1. Summoning Execute:

To open Execute, simply use the shortcut Ctrl + Shift + Space

Tried it? Nice! Let's move on to the next step.

2. Search Google using Execute:

Instead of opening an entire tab to browse google, you can finally just access it immediately on Execute!

3. Calculate using Execute:

By using the command "=", you can immediately calculate using Execute!

4. Open websites using Execute:

By using the command "@", you can access websites immediately on Execute!

You're all set!
